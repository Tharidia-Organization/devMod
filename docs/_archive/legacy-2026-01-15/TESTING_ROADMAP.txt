EDGE CASES & CRITICAL FAILURES TO TEST
================================================================================

1. Null Safety (applies to all components)
   - DamageHandler with null event.getSource()
   - HitHelper with null attacker
   - Config with null ItemStack
   - Should log error, not crash

2. Float Precision (affects gameplay accuracy)
   - Damage multiplier: 0.7f vs 0.70000012f
   - Network serialization round-trip
   - Scale calculations (Pehkui 1.005x)
   - Use epsilon comparison (1e-6), not ==

3. Thread Safety (affects stability)
   - HitContext concurrent store/retrieve/cleanup
   - TelemetryService ConcurrentHashMap operations
   - 100+ concurrent damage events
   - No ConcurrentModificationException, no data loss

4. Memory Leaks (affects server stability over time)
   - HitHelper cache max 1000 entries, cleanup every 5s
   - HitContext TTL 100ms, auto-cleanup
   - Weak references to entities must allow GC
   - Monitor heap growth with 10K entity tracker

5. Config Load Order (affects initialization)
   - WeaponStats defaults depend on Config
   - Test with/without Config loaded
   - Fallback values when Config missing
   - Test late Config reload

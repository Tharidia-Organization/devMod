## Entrypoints

### /devtest Commands (OP level 2)

- HUD: `devtest hud on|off|toggle|export|import`
- Panels: `devtest panel on|off|toggle`, `devtest panelclear`
- Debug: `devtest debug on|off|toggle`, `devtest debugbox <size>`, `devtest debugclear`
- QA: `devtest qa`
- Body part info: `devtest bodypart <part>`
- Endurance utilities: `devtest endurance stats|perks|smoke|autosmoke|export <table|all>`
- Status: `devtest info`

Notes:
- Client-side commands route through `TestHarnessClientDelegate`.
- `devtest qa` opens the Testing Hub UI.

## Autosmoke Flow

- `AutosmokeGuard` gates runs via env var, feature flag, and marker file checks.
- `AutosmokeScheduler` drives scheduled runs; `AutosmokeRunner` executes them.
- Reports are generated by `AutosmokeReportWriter` using threshold metadata.
